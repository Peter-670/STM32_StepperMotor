# 激光调谐装置 - 步进电机驱动控制系统 说明文档

本文档基于**鑫飞FEX4015-LBN电动滑台**、**STM32主控**、**DRV8825驱动芯片**打造，用于激光器谐振腔长与极化周期精准调谐，支持串口指令控制、限位保护、位移累计、紧急停止等功能，可通过通用串口助手快速操作。

---

## 项目概述

本项目为**激光自动调谐装置**的核心运动控制单元，通过步进电机驱动电动滑台精准位移，实现激光器谐振腔长与PPLN晶体极化周期的同步匹配与扫描控制。

### 核心功能

1. 步进电机正/反转方向控制
2. 定长位移（整圈/半圈/微米级任意位移）
3. 硬件限位保护（正限位/负限位/原点）
4. 紧急停止与状态恢复
5. 位移累计统计（步数追踪，0.1μm显示精度）
6. 串口实时状态反馈与指令校验
7. 步进过程中在线限位检测
8. 适配激光调谐高精度位移需求

- 最大速度：20mm/s
- 重复定位精度：≤±1.5μm
- 电机额定电流：1.3A

## 软件系统

### 开发环境

- 编译环境：Keil MDK5
- 配置工具：STM32CubeMX
- 库文件：STM32F1xx HAL库
- 下载工具：ST-LINK

### 核心软件逻辑

1. **GPIO位带脉冲生成**：软件延时方式在STEP引脚产生方波，驱动电机精准位移
2. **串口指令解析**：支持3位数字指令、L/R微米指令、复位指令、位置查询
3. **限位保护**：实时检测限位信号，2ms延迟+3次连续确认去抖，触发后紧急停止并方向锁定
4. **位移统计**：基于步数（int32_t）累计，0.1μm精度显示
5. **步进中限位检测**：每100步检测一次限位，支持运动中紧急停止
6. **原点逻辑**：原点触发仅清零位移数据，不触发报警锁定

## 串口通信协议

### 串口基础配置

- 波特率：**115200 bps**
- 数据位：8位
- 停止位：1位
- 校验位：无
- 流控：无
- 指令结尾：回车/换行（\r\n）

### 标准指令表

| 指令类型   | 格式               | 说明                                                         |
| ---------- | ------------------ | ------------------------------------------------------------ |
| 3位数字指令 | `<速度><方向><圈数>` | 速度1-3 / 方向0-1 / 圈数1-2。例：`201`=中速正转整圈          |
| 微米位移   | `L<距离>`          | CW（正转）方向位移指定微米数。例：`L100`=CW位移100μm         |
| 微米位移   | `R<距离>`          | CCW（反转）方向位移指定微米数。例：`R1000`=CCW位移1000μm=1mm |
| 复位指令   | `R`（单独发送）    | 解除报警锁定，恢复电机正常运行                                |
| 查询指令   | `?`                | 查询当前累计位移位置                                          |

### 指令参数说明

| 参数 | 取值    | 说明                                        |
| ---- | ------- | ------------------------------------------- |
| 速度 | 1/2/3   | 1=低速 2=中速（L/R指令默认） 3=高速 |
| 方向 | 0/1     | 0=正转(CW) 1=反转(CCW)                      |
| 圈数 | 1/2     | 1=整圈(6400步=1mm) 2=半圈(3200步=0.5mm)      |
| 距离 | 1~15000 | 微米单位，最大15mm（对应滑台±7.5mm行程+余量）  |

### 换算关系

- 6400 脉冲 = 1 圈 = 1 mm = 1000 μm
- 1 脉冲 = 0.15625 μm
- N μm → 步数 = N × 6400 ÷ 1000（整数运算）

### 限位说明

- 硬件引脚：PB3（正转限位）、PB4（反转限位）、PB5（原点）
- 触发逻辑：高电平有效，2ms延迟确认 + 连续3次检测（抗干扰）
- 动作区分：正/反转限位触发→紧急停止+报警锁定+方向锁定；原点触发→仅清零位移
- 复位后：若限位仍触发，方向锁定保持，仅允许反向离开

### 系统反馈说明

1. 初始化反馈：系统启动后输出中文指令说明、参数信息
2. 运行反馈：指令确认（位移量、步数换算）、执行完成（当前位置，0.1μm精度）
3. 报警反馈：限位类型提示 + 复位指引
4. 错误反馈：非法指令提示 + 缓冲区自动清除

## 串口助手使用步骤

### 步骤1：硬件接线与通电

1. 严格按照引脚分配完成主控、驱动、滑台、电源接线
2. 所有模块共地（GND连通），避免信号干扰
3. 先接主控电源，再接24V滑台电源，检查指示灯正常

### 步骤2：串口助手配置

1. 选择对应COM口，设置波特率115200
2. 勾选**自动换行**、**发送新行**
3. 打开串口，查看初始化信息，确认系统正常

### 步骤3：指令操作示例

```text
L100    → CW方向位移 100μm（640步）
R500    → CCW方向位移 500μm（3200步）
R1000   → CCW方向位移 1000μm = 1mm（6400步）
101     → 低速正转整圈（1mm）
321     → 高速反转半圈（0.5mm）
R       → 解除报警锁定
?       → 查询当前位置
```

**注意事项：**
- 报警后发送 `R` 解除锁定，然后只能反方向发送移动指令离开限位
- 固定电机远离旋钮的方向为正方向（CW），靠近旋钮的方向为反方向（CCW）
- 上电后当前位置自动归零

## 常见故障排查

| 故障现象         | 原因              | 解决方案                                |
| ---------------- | ----------------- | --------------------------------------- |
| 串口无初始化信息 | 波特率错误/接线反 | 核对115200波特率，TX/RX交叉接线         |
| 电机震动不转     | 电流不足/细分错误 | 调整驱动电流至1.2A，检查细分设置        |
| 限位触发无法运行 | 滑台超行程        | 手动复位滑台，发送`R`恢复              |
| 位移不准/丢步    | 供电不稳/机械卡滞 | 检查24V电源，清理滑台异物               |
| 限位信号无法检测 | 电压不匹配/未共地 | 统一GND，增加电平转换电路               |
