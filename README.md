# STM32_StepperMotor

基于 **STM32F103C8T6 + DRV8825** 的步进电机控制项目，用于高精度直线位移场景（如激光调谐、微米级定位等）。  
本仓库用于保存项目**历代版本代码**与文档。

## 项目目标

- 支持串口指令控制步进电机运动
- 支持微米级位移控制
- 支持双限位保护与原点检测
- 支持位置累计与状态查询
- 便于版本归档、回溯与发布

## 快速开始

1. 进入你需要的版本目录（建议 V9）。
2. 用 Keil 打开对应工程文件（`.uvprojx`）。
3. 连接 ST-Link 下载程序。
4. 串口参数设置为 `115200 8N1`，开始发送控制指令。

## 硬件平台

- MCU: STM32F103C8T6
- Driver: DRV8825
- Motor: 两相步进电机（配合丝杆滑台）
- 通信: USART1 (PA9/PA10)

## 主要功能（以 V9 为主）

- 3 位快捷指令控制速度、方向、圈数
- `A<dist>` / `B<dist>` 微米位移指令
- `?` 查询当前位置
- `R` 复位报警状态
- A/B 双方向限位锁定与释放
- 运动过程中的快速限位检测

## 串口指令示例

```text
201     -> 中速 A 方向整圈
321     -> 高速 B 方向半圈
A100    -> A 方向移动 100um
B1000   -> B 方向移动 1000um
?       -> 查询位置
R       -> 复位报警
```
